# MACD多时间框架交易策略 V1.0

## 一、策略概述

本策略基于MACD指标的多时间框架分析，通过不同周期MACD的层级分工，实现趋势方向的确认和入场时机的优化。

### 核心理念

```
┌─────────────────────────────────────────────────────────┐
│                   MACD策略层级架构                        │
├─────────────────────────────────────────────────────────┤
│  MACD_1H (定方向)                                        │
│    → 柱子翻红/翻绿/缩短等确认买卖方向                      │
│    → 核心决策层，权重40%                                  │
├─────────────────────────────────────────────────────────┤
│  MACD_4H (确认增强)                                      │
│    → 同向增强信号，不作为买卖点                           │
│    → 趋势验证层，权重20%                                  │
├─────────────────────────────────────────────────────────┤
│  MACD_15M (跟随入场)                                     │
│    → 跟随1H方向执行买卖                                   │
│    → 入场执行层，权重25%                                  │
├─────────────────────────────────────────────────────────┤
│  成交量确认                                              │
│    → 验证入场质量                                        │
│    → 辅助验证层，权重15%                                  │
└─────────────────────────────────────────────────────────┘
```

### 扫描周期

- **入场扫描周期**: 每15分钟
- **主要分析周期**: 1小时
- **趋势确认周期**: 4小时

## 二、MACD参数配置

| 周期 | 快线 | 慢线 | 信号线 |
|------|------|------|--------|
| 15M | 12 | 26 | 9 |
| 1H | 12 | 26 | 9 |
| 4H | 12 | 26 | 9 |

**MACD计算公式**:
```
MACD线 = EMA(12) - EMA(26)
信号线 = EMA(MACD线, 9)
柱状图 = MACD线 - 信号线
```

## 三、MACD_1H 定方向（核心决策层）

### 3.1 信号类型与强度

| 信号类型 | 触发条件 | 方向 | 信号强度 | 说明 |
|----------|----------|------|----------|------|
| **翻红** | hist_1 ≤ 0 且 hist_0 > 0 | 做多 | 1.0 | MACD柱从负转正，最强做多信号 |
| **翻绿** | hist_1 ≥ 0 且 hist_0 < 0 | 做空 | 1.0 | MACD柱从正转负，最强做空信号 |
| **红柱增长** | hist_0 > 0, hist_1 > 0, hist_0 > hist_1 | 做多 | 0.8 | 多头动能增强 |
| **绿柱增长** | hist_0 < 0, hist_1 < 0, hist_0 < hist_1 | 做空 | 0.8 | 空头动能增强 |
| **红柱缩短** | hist_0 > 0, hist_1 > 0, hist_0 < hist_1 | 无 | 0.0 | 多头减弱，不入场 |
| **绿柱缩短** | hist_0 < 0, hist_1 < 0, hist_0 > hist_1 | 无 | 0.0 | 空头减弱，不入场 |

### 3.2 信号检测逻辑

```python
# 伪代码表示
def detect_1h_direction(hist_current, hist_prev):
    
    # 翻红检测（负转正）
    if hist_prev <= 0 and hist_current > 0:
        return 'long', strength=1.0, type='flip_bullish'
    
    # 翻绿检测（正转负）
    if hist_prev >= 0 and hist_current < 0:
        return 'short', strength=1.0, type='flip_bearish'
    
    # 红柱增长（多头增强）
    if hist_current > 0 and hist_prev > 0 and hist_current > hist_prev:
        return 'long', strength=0.8, type='red_bar_growing'
    
    # 绿柱增长（空头增强）
    if hist_current < 0 and hist_prev < 0 and hist_current < hist_prev:
        return 'short', strength=0.8, type='green_bar_growing'
    
    # 红柱缩短（多头减弱，不入场）
    if hist_current > 0 and hist_prev > 0 and hist_current < hist_prev:
        return None, strength=0.0, type='red_bar_shrinking'
    
    # 绿柱缩短（空头减弱，不入场）
    if hist_current < 0 and hist_prev < 0 and hist_current > hist_prev:
        return None, strength=0.0, type='green_bar_shrinking'
    
    return None
```

### 3.3 关键规则

> ⚠️ **重要**: MACD_1H柱子缩短时（无论红绿），**不产生入场信号**，表示动能减弱。

## 四、MACD_4H 确认增强（趋势验证层）

### 4.1 功能定位

- **不作为买卖点**，只用于确认趋势强度
- 当4H与1H方向一致时，增强信号可信度
- 当4H与1H方向相反时，**不拒绝入场**，只降低评分

### 4.2 增强评分逻辑

#### 做多方向时：

| 4H条件 | 基础分 | 增强分 | 总分 | 是否增强 |
|--------|--------|--------|------|----------|
| hist > 0 且在增长 | 0.5 | +0.3 | 0.8 | ✅ 是 |
| hist > 0 且在缩短 | 0.5 | +0.1 | 0.6 | ❌ 否 |
| hist ≤ 0（方向相反） | 0 | 0 | 0 | ❌ 否 |

#### 做空方向时：

| 4H条件 | 基础分 | 增强分 | 总分 | 是否增强 |
|--------|--------|--------|------|----------|
| hist < 0 且在下降 | 0.5 | +0.3 | 0.8 | ✅ 是 |
| hist < 0 且在回升 | 0.5 | +0.1 | 0.6 | ❌ 否 |
| hist ≥ 0（方向相反） | 0 | 0 | 0 | ❌ 否 |

### 4.3 关键规则

> ⚠️ **重要**: 4H方向相反**不拒绝入场**，只是在评分系统中降低权重。

## 五、MACD_15M 跟随入场（入场执行层）

### 5.1 功能定位

- **不能作为方向判断的关键点**
- 只负责在1H确定方向后，寻找最佳入场时机
- 必须与1H方向一致才能入场

### 5.2 入场类型与评分

#### 做多跟随（1H方向=long）：

| 入场类型 | 触发条件 | 入场评分 | 说明 |
|----------|----------|----------|------|
| **翻红跟随** | hist_1 ≤ 0 且 hist_0 > 0 | 1.0 | 最强入场，15M刚翻红 |
| **红柱增长** | hist_0 > 0, hist_1 > 0, hist_0 > hist_1 | 0.85 | 强入场，动能增强 |
| **红柱稳定** | hist_0 > threshold 且 hist_0 > 0 | 0.6 | 中等入场，稳定跟随 |
| **红柱缩短** | hist_0 > 0, hist_1 > 0, hist_0 < hist_1 | 0.3 | 弱入场，动能减弱 |

#### 做空跟随（1H方向=short）：

| 入场类型 | 触发条件 | 入场评分 | 说明 |
|----------|----------|----------|------|
| **翻绿跟随** | hist_1 ≥ 0 且 hist_0 < 0 | 1.0 | 最强入场，15M刚翻绿 |
| **绿柱增长** | hist_0 < 0, hist_1 < 0, hist_0 < hist_1 | 0.85 | 强入场，动能增强 |
| **绿柱稳定** | hist_0 < -threshold 且 hist_0 < 0 | 0.6 | 中等入场，稳定跟随 |
| **绿柱缩短** | hist_0 < 0, hist_1 < 0, hist_0 > hist_1 | 0.3 | 弱入场，动能减弱 |

### 5.3 MACD阈值

```python
MACD_THRESHOLD = 0.00005  # 避免在震荡区误入场
```

当MACD柱绝对值小于阈值时，视为震荡区，不产生入场信号。

### 5.4 关键规则

> ⚠️ **重要**: 15M柱子缩短时**仍可入场**，但评分降低（0.3），需综合其他因素判断。

## 六、综合评分系统

### 6.1 评分权重分配

| 评分模块 | 权重 | 最大得分 |
|----------|------|----------|
| MACD_1H 定方向 | 40% | 0.40 |
| MACD_4H 增强确认 | 20% | 0.20 |
| MACD_15M 跟随入场 | 25% | 0.25 |
| 成交量确认 | 15% | 0.15 |
| **总计** | **100%** | **1.00** |

### 6.2 详细评分计算

#### 1H定方向评分（满分0.40）：

```python
if signal_type in ['flip_bullish', 'flip_bearish']:
    score_1h = 0.40  # 翻红/翻绿，满分
elif signal_type in ['red_bar_growing', 'green_bar_growing']:
    score_1h = 0.35  # 柱子增长，87.5%
else:
    score_1h = 0.25 * signal_strength  # 其他情况
```

#### 4H增强评分（满分0.20）：

```python
if is_4h_enhanced:
    score_4h = 0.20 * enhancement_score  # 完全增强
elif enhancement_score > 0:
    score_4h = 0.10 * enhancement_score  # 部分增强
else:
    score_4h = 0  # 无增强
```

#### 15M入场评分（满分0.25）：

```python
if entry_type in ['flip_bullish', 'flip_bearish']:
    score_15m = 0.25  # 翻红/翻绿跟随，满分
elif entry_type in ['red_bar_growing', 'green_bar_growing']:
    score_15m = 0.22  # 柱子增长跟随，88%
elif entry_type in ['red_bar_stable', 'green_bar_stable']:
    score_15m = 0.18  # 稳定跟随，72%
else:
    score_15m = 0.10  # 柱子缩短跟随，40%
```

#### 成交量评分（满分0.15）：

```python
if volume_ratio > 1.5:
    score_volume = 0.15  # 显著放量（>1.5倍）
elif volume_ratio > 1.0:
    score_volume = 0.10  # 放量确认（>1倍）
else:
    score_volume = 0.05  # 缩量
```

### 6.3 入场阈值

| 阈值参数 | 默认值 | 说明 |
|----------|--------|------|
| `min_entry_score` | 0.30 | 15M入场最低评分 |
| `min_signal_score` | 0.45 | 综合信号最低评分 |

**入场条件**:
```
1. 1H有明确方向（非柱子缩短）
2. 15M入场评分 ≥ 0.30
3. 综合信号评分 ≥ 0.45
```

- **初始止损**: 入场价下方 2%

## 十、策略优势与局限

### 10.1 优势

1. **层级分明**: 1H定方向、4H确认、15M入场，职责清晰
2. **避免追高杀跌**: 柱子缩短时不入场，避免在动能减弱时入场
3. **灵活性高**: 4H方向相反不拒绝入场，只是降低评分
4. **提前入场**: 基于柱子变化而非金叉死叉，比传统方法提前2-3根K线
5. **风控完善**: 基于评分动态调整杠杆和仓位

### 10.2 局限性

1. **震荡市场表现一般**: 横盘震荡时MACD信号频繁切换
2. **极端行情风险**: 黑天鹅事件可能导致超预期亏损
3. **参数敏感性**: MACD参数(12,26,9)可能不适用所有币种
4. **假信号风险**: 柱子翻红/翻绿可能是假突破

### 10.3 改进方向

1. 添加ADX过滤，在无趋势时减少交易
2. 结合RSI超买超卖区域过滤
3. 添加支撑阻力位确认
4. 优化不同币种的MACD参数

## 十二、总结

本策略通过MACD多时间框架分析，实现了：

1. **方向确定性**: 1H MACD柱子变化作为核心方向判断
2. **趋势验证**: 4H MACD作为增强确认
3. **精准入场**: 15M MACD跟随入场，优化入场时机
4. **风险控制**: 基于评分的动态杠杆和仓位管理

**核心思想**: 让大周期定方向，小周期找入场，中周期做验证。
