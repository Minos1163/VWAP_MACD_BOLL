## 📈 二、开仓逻辑详解

### 2.1 信号评分体系

#### 2.1.1 基础评分权重

策略采用多维度加权评分系统：

```python
signal_score = (
    score_4h_direction × 0.40 +      # 4H 主趋势方向 (最高权重 40%)
    score_1h_direction × 0.20 +      # 1H 辅助确认 (权重 20%)
    score_vwap       × 0.20 +        # VWAP 偏离度评分 (权重 20%)
    score_volume     × 0.15 +        # 成交量确认 (权重 15%)
    score_15m_entry  × 0.05          # 15M 入场时机 (最低权重 5%)
)
```

**各维度评分说明**:

1. **4H 方向得分 (40%)**: 
   - 基于 4H MACD 柱状图方向和强度
   - 判断主趋势方向 (多头/空头/中性)
   - 权重最高，因为大周期趋势最可靠

2. **1H 方向得分 (20%)**:
   - 基于 1H MACD 和 EMA 结构
   - 辅助确认 4H 方向
   - 降低假信号干扰

3. **VWAP 得分 (20%)**:
   - 计算当前价格相对 VWAP 的偏离度
   - 避免追高杀跌
   - 评估入场价值

4. **成交量得分 (15%)**:
   - 确认价格变动的有效性
   - 放量突破得分更高
   - 增加信号可信度

5. **15M 入场得分 (5%)**:
   - 基于 15M MACD 和 K 线形态
   - 选择最佳入场时机
   - 权重最低，避免过度拟合短期波动

#### 2.1.2 信号类型与阈值要求

| 信号类型 | 最低分数要求 | 出现场景 |
|----------|-------------|----------|
| **default** | 0.830 | 默认信号阈值 |
| **red_bar_growing** | 0.845 | 红柱增长 (多头延续信号) |
| **flip_bearish** | 0.825 | 翻转做空信号 |
| **flip_bullish** | 0.825 | 翻转做多信号 |
| **stable_bear_continuation** | 0.800 | 稳定空头延续 |
| **stable_bull_continuation** | 0.800 | 稳定多头延续 |

**注**: 所有信号必须同时满足全局最低门槛 `min_entry_score = 0.25`

### 2.2 硬性过滤条件 (L1 结构层)

#### 2.2.1 基础结构过滤

```json

  "entry_hard_gate_adx_min": 22,           // ADX 最低 22 (趋势强度门槛)
  "entry_hard_gate_atr_min": 0.006,        // ATR 最低 0.6% (波动率下限)
  "entry_hard_gate_atr_max": 0.02,         // ATR 最高 2% (波动率上限)
  "entry_hard_gate_spread_bps_max": 0.0008,// 点差最高 0.8bps (流动性门槛)
  "entry_hard_gate_flow_min_pass": 2,      // 资金流最少 2 项通过
  "entry_hard_gate_micro_min_pass": 2      // 微观结构最少 2 项通过
}
```

**L1 过滤失败场景**:

| 条件 | 含义 | 结果 |
|------|------|------|
| ADX < 22 | 市场无趋势，处于震荡 | 拒绝开仓 |
| ATR < 0.6% | 波动率不足，行情停滞 | 拒绝开仓 |
| ATR > 2% | 波动率过热，风险过高 | 拒绝开仓 |
| 点差 > 0.8bps | 流动性不足，成本高 | 拒绝开仓 |
| 资金流 < 2 项通过 | 资金面不支持 | 拒绝开仓 |
| 微观结构 < 2 项通过 | 盘口结构不健康 | 拒绝开仓 |

## ⚖️ 四、权重体系

### 4.1 信号评分权重

**公式**:
```
signal_score = (
  4H 方向得分 × 0.40 +
  1H 方向得分 × 0.20 +
  VWAP 得分   × 0.20 +
  成交量得分  × 0.15 +
  15M 入场得分 × 0.05
)
```

**权重分配逻辑**:

| 维度 | 权重 | 理由 |
|------|------|------|
| 4H 方向 | 40% | 大周期趋势最可靠，权重最高 |
| 1H 方向 | 20% | 辅助确认，降低假信号 |
| VWAP | 20% | 价值评估，避免追高杀跌 |
| 成交量 | 15% | 动能确认，增加可信度 |
| 15M 入场 | 5% | 时机选择，避免过度拟合短期 |
