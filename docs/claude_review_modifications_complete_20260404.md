## 📈 预期性能

基于新配置的月度预期（20 个交易日）：

**假设条件**:
- 日均交易：4 笔
- 胜率：50%
- 盈亏比：2:1 (止盈 4% / 止损 2%)
- 平均仓位：25%
- 平均杠杆：2x

**计算**:
```
总交易数 = 4 × 20 = 80 笔
盈利交易 = 80 × 50% = 40 笔
亏损交易 = 80 × 50% = 40 笔

单笔盈利 = 25% × 2x × 4% = 2.0% 账户收益
单笔亏损 = 25% × 2x × 2% = 1.0% 账户损失

总盈利 = 40 × 2.0% = 80%
总亏损 = 40 × 1.0% = 40%
净收益 = 80% - 40% = 40%

扣除手续费 ≈ 1.0%
最终月收益 ≈ 39%
```

**风险提示**: 这是理想情况下的理论计算，实际表现可能因市场波动、滑点、执行偏差等因素而有所不同。
