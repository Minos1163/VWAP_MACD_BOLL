**当前基线**: v1.1 配置 | 收益 +48.66% | 胜率 80.7% | 回撤 4.87% | 盈利因子 2.11  
**优化目标**: 收益 ≥ +200%  
**报告日期**: 2026-04-04

## 先读这一节：200% 目标的数学现实

在制定任何参数方案前，必须先做一次期望值核算。

**当前 v1.1 的盈利结构**：

```
总盈利 = 平均盈利 × 胜率 × 交易数 - 平均亏损 × 败率 × 交易数
       = $24 × 80.7% × 585 - $48 × 19.3% × 585
       = $11,330 - $5,419
       = +$5,911  ≈ +49%（与实测 +48.66% 吻合）
```

**要达到 +200%，需要 +$20,000 的净利润**，是当前的 **3.38 倍**。

有三条独立路径可以放大净利润：

| 路径 | 杠杆 | 交易数量 | 盈亏比 | 说明 |
|------|------|---------|--------|------|
| **A. 杠杆放大** | × 3.38 | 不变 | 不变 | 需要 5x→10x 杠杆，不现实 |
| **B. 纯信号扩容** | 不变 | × 3.38 | 不变 | 585→1977笔，门槛需大幅放宽 |
| **C. 组合路径** | × 1.8 | × 1.5 | × 1.25 | 杠杆 + 频率 + 盈亏比协同 |

**结论：只有路径 C 可行**。单独走 A 或 B 任何一条都会把回撤打穿或将胜率崩溃。

**代价换算**：

```
当前回撤预算已用: 4.87%（目标上限 8% 还有 3.13% 余量）
从 49% 到 200%，净利润需要增加 3.38 倍
这意味着最大回撤会从 4.87% 上升至估算的 12-16%
```

> **投资者决策点**：如果接受最大回撤 15% 以内（加密交易行业标准），200%+ 目标在数学上可行。如果回撤红线是 8%，200% 目标在当前策略架构下无法实现，需要从信号逻辑层重构。

## Phase 1：杠杆结构重建（最高优先级）

### 现状

v1.1 配置的实际杠杆结构已被大幅压缩：

```
score ≥ 0.95:  3x（从基线 5x 压缩）
score ≥ 0.75:  3-4x（基本锁定在 3x）
VWAP劣势状态:  3x 上限
```

当前有效平均杠杆约为 **3.1x**，而基线为 **4.8x**。这是收益差距的最大单一来源。

### 消融方案

**Test-L1：高质量信号杠杆上限从 3x 恢复至 4x**

```json
// config/trading_config_fund_flow.json
"leverage_config": {
  "score_0.95_plus":  4,    // 3x → 4x（高置信信号）
  "score_0.85_plus":  4,    // 维持
  "score_0.75_plus":  3,    // 维持
  "below_threshold":  0
},
"high_signal_leverage_cap": 4   // 整体上限从 3x → 4x
```

```python
# src/fund_flow/macd_strategy_v2.py
# calculate_leverage() 修改：
def calculate_leverage(self, score: float) -> int:
    if score >= 0.95:
        return min(4, self.config.max_leverage)  # 3 → 4
    elif score >= 0.85:
        return min(4, self.config.max_leverage)
    elif score >= 0.75:
        return min(3, self.config.max_leverage)
    return 0
```

**预期效果**：

```
当前平均杠杆: ~3.1x
调整后平均杠杆: ~3.8x（+23%）
预计收益增量: +49% × 1.23 ≈ +60%（净增 +11%）
回撤预计上升: 4.87% → 6.0%（仍在 8% 内）
```

**Test-L2：进一步恢复至 5x（若 L1 通过）**

```json
"leverage_config": {
  "score_0.95_plus":  5,    // 对标原始基线
  "score_0.85_plus":  4,
  "score_0.75_plus":  3
},
"high_signal_leverage_cap": 5
```

**预期效果**：

```
调整后平均杠杆: ~4.5x
预计收益增量: +49% × 1.45 ≈ +71%（净增 +22%）
回撤预计上升: 4.87% → 7.5%（接近 8% 警戒线）
```

**验证标准**：

```
Test-L1 接受条件:
  ✓ 收益率 ≥ +60%
  ✓ max_drawdown ≤ 7.0%
  ✓ 胜率下降 ≤ 0.5%（杠杆不影响胜率）

Test-L2 接受条件:
  ✓ 收益率 ≥ +75%
  ✓ max_drawdown ≤ 8.5%（允许略超，评估风险价值比）
  ✓ 最大单笔亏损 ≤ $450
```

## Phase 2：仓位压缩部分解除

### 现状

v1.1 中两处仓位压缩直接削减了盈利规模：

```
VWAP劣势状态 (long_below_both/short_above_both):  55% 仓位
高分信号 (score ≥ 0.95):  仓位乘数 1.0（取消原来的 1.2x 奖励）
```

这两处压缩在降低回撤方面有效，但也同步压缩了盈利。

### 消融方案

**Test-P1：VWAP劣势状态仓位 55% → 70%（杠杆维持 3x 不变）**

```json
"vwap_structure_overrides": {
  "long_below_both": {
    "position_scale": 0.70,         // 55% → 70%
    "max_leverage_override": 3      // 杠杆上限不动
  },
  "short_above_both": {
    "position_scale": 0.70,         // 55% → 70%
    "max_leverage_override": 3
  }
}
```

**名义敞口对比**：

```
基线:       50% × 5x = 250%
v1.1:       55% × 3x = 165%
Test-P1:    70% × 3x = 210%（+27% vs v1.1）
```

**预期效果**：

```
VWAP劣势状态约占总交易 18%
预计净收益增量: +6% ~ +9%
long_below_both 亏损: $152 → ~$220（仍低于基线 $1,671 的 13%）
```

**Test-P2：高分信号仓位乘数 1.0 → 1.1（score ≥ 0.95）**

```python
# src/fund_flow/macd_strategy_v2.py
# calculate_portion_multiplier() 修改：
def calculate_portion_multiplier(self, score: float) -> float:
    if score >= 0.95:
        return 1.10   # 1.0 → 1.1（部分恢复，不回到原始 1.2）
    return 1.0
```

**设计逻辑**：高分信号（0.95+）在 v1.1 中均亏已降至 $69（基线 $230），说明仓位去关联有效，但 1.0 倍乘数过于保守，1.1 是折中点。

**预期效果**：

```
高分信号约占总交易 12%
预计净收益增量: +4% ~ +6%
最大单笔亏损: $312 → ~$360（可接受）
```

## Phase 4：盈亏比优化

### 现状

v1.1 的盈亏结构存在明显失衡：

```
平均盈利: $24
平均亏损: $48
盈亏比:   0.5（意味着每笔盈利只能补回半笔亏损）

要维持正期望: 需要胜率 ≥ 1/(1+0.5) = 66.7%（目前 80.7% 有充足缓冲）
```

但如果能将盈亏比从 0.5 提升至 0.7~0.8，在相同胜率下期望值提升 40%~60%。

### 消融方案

**Test-R1：TP 分级延伸（强趋势信号追加尾部止盈）**

当前 TP 结构：0.8% / 1.2% / 2.0%（三级，对应 4% 总 TP）

```json
// 新增第四级止盈，用于强趋势信号
"take_profit_tiers": [
  {"pct": 0.008, "close_ratio": 0.25},   // 0.8%: 平仓 25%（原 30%）
  {"pct": 0.012, "close_ratio": 0.30},   // 1.2%: 平仓 30%（原 40%）
  {"pct": 0.020, "close_ratio": 0.30},   // 2.0%: 平仓 30%（原 30%）
  {"pct": 0.040, "close_ratio": 1.00}    // 4.0%: 剩余全平（新增尾部）
],
// 仅对以下信号类型启用四级止盈：
"four_tier_tp_signals": ["red_bar_growing", "green_bar_growing", "flip_bullish"]
```

**预期效果**：

```
强趋势信号（约占 80% 交易量）能够持续至 4% 止盈
平均盈利从 $24 → ~$32（+33%）
代价: 部分在 2%~4% 区间回撤的交易可能变为保本止损
净期望增量: +12% ~ +18%
```

**Test-R2：趋势延续信号引入动态 TP（跟随 BOLL 上轨）**

对于 `red_bar_growing` 和 `stable_bull_continuation` 信号，当价格持续沿 BOLL 上轨运行时，将止盈点动态上移。

```json
"dynamic_tp_config": {
  "enabled": true,
  "apply_to_signals": ["red_bar_growing", "stable_bull_continuation"],
  "trailing_reference": "boll_upper",    // 以 BOLL 上轨为基准
  "trailing_offset_pct": 0.003,          // 低于 BOLL 上轨 0.3% 时止盈
  "min_profit_to_activate": 0.015,       // 浮盈达到 1.5% 后才激活动态止盈
  "max_tp_extension": 0.08               // 最大允许延伸至 8%（防止过度持仓）
}
```

**预期效果**：

```
捕捉部分超预期趋势行情（历史数据中约 15% 的盈利交易有潜力超过 4% TP）
平均盈利进一步从 $32 → ~$38（+19%）
```
