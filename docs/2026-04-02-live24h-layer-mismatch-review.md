# Live 24H vs Pure Strategy — 层级错位审查

日期: `2026-04-02`  
审查口径: hostile reviewer  
核心问题: 当前主战场是否已经切回前段，而不是 execution layer

---

## 1. 总判断

**层级错位判断成立，但不能据此直接开始调前段。**

这 24H 窗口的数据质量足够清晰：`entry_hard_gate_block = 0`、`pretrade PASS = 3581`，这两个数字把后段的责任完全洗清了。主阻挡确实在前段，这一点不需要再争。

但这里有一个逻辑陷阱需要先挑出来：**一个 live 窗口不能代表系统性问题，它也可能代表市场窗口本身就不适合开仓。** 在把战场切到前段之前，必须先确认这 24H 的 `vwap_hard_block / volume_vwap_both_low` 是"门槛错误"还是"市场本来如此"。这两者的处理方向完全相反。

---

## 2. 我同意的部分

**同意：当前这 24H live 的主阻挡确实在前段，execution layer 的优化对它无效。**

数字直接说明问题：`1783 vwap_hard_block + 1112 volume_vwap_both_low + 605 4H预翻转 = 3500`，占 `3581` 次决策的 `97.74%`。这些阻挡发生在系统甚至走到 `entry_hard_gate` 之前，所以最近所有针对 same-bar、runner、AI shortlist、candidate ledger 的修复，在这个窗口里没有触发机会。

**同意：最近大量修复与 live 主阻挡层级错位，这解释了"修了很多次还是没有开仓"。**

这不是修复无效，而是修复的是另一个问题。那些修复让 bot-like 回测口径更真实，这个价值仍然存在。但它们不改变前段 veto 的判定结果。两件事在不同层面上都是对的，不互相否定。

**同意：同窗口里 pure 自己也没有 entry，"拆门槛就回到 pure"站不住。**

这是当前最重要的事实约束。如果 pure 在这 24H 也没有产生任何 entry，那这个窗口本身就不是一个"pure 大量交易但 live 被外层卡死"的场景。"拆门槛等于 pure"这个说法在这个窗口里连前提都不成立。

---

## 3. 我反对的部分

**反对：用一个 24H 窗口得出"主战场应该切回前段"这个系统性结论。**

这个窗口的证据证明的是："这 24 小时里，前段是主阻挡。"它不能证明："过去 30 天里，前段都是主阻挡。"

如果要把"主战场切回前段"作为下一步方向，需要的证据是：**在 pure 策略过去 30 天有 1007 笔 entry 的同一时间段内，live 里 VWAP/volume/4H 这三层的阻挡频率分布是什么。** 一个单独的 24H 窗口，尤其是在已知市场处于 `PASSIVE_ONLY 70.09% / BLOCK 27.28%` 的微观结构质量极差的状态下，不能代表系统性结论。

**反对：把 `volume_vwap_both_low 31.05%` 直接理解为"过度压制"。**

`volume_vwap_both_low` 是一个复合条件，它的触发意味着 volume 和 VWAP 同时偏弱。在 microstructure 质量极差（`PASSIVE_ONLY 70%`）的窗口里，这个条件触发频率高是正常的，它可能在保护资金不进入流动性差的市场。在没有对应的后验价格数据支撑之前，把它标记为"过度压制"是不成立的。

---

## 4. 我认为最危险的误判

**最危险的误判：把"前段是主阻挡"理解成"前段门槛定高了"。**

这是一个看起来合理、但逻辑跳步的推断。前段阻挡频率高，有两种完全相反的解释：

- **解释 A：** 门槛偏高，导致本该进入的机会被错误过滤。→ 应该放宽。
- **解释 B：** 市场本来就不满足条件，门槛在正确执行任务。→ 不应该动。

当前 24H 数据无法区分这两种解释。已有的扩样本证据（`vwap_hard_block long 2h avg +0.1254%`）对 long 侧偏紧有轻微支持，但远不足以支撑全局放宽的决策。

如果在没有区分这两种解释之前就开始拆前段门槛，等于在一个不清楚是"门槛错了"还是"市场本来如此"的系统上做随机干预。这个风险比继续修 execution layer 要高得多，因为前段改动的影响面是全局的，而 execution layer 的修复通常是局部的、可回滚的。

---

## 5. 下一步只保留 3 项

**第一项：拉 30 天 live attribution 分布，确认前段 veto 是否是系统性问题**

目标：统计过去 30 天 live 里 `vwap_hard_block / volume_vwap_both_low / 4H preflip` 的日均触发次数和日均占比，与这 24H 窗口对比。  
如果 30 天均值与这 24H 接近，说明是系统性问题，前段值得优先审。  
如果这 24H 是异常高点，说明它是市场窗口问题，前段门槛不是首要目标。  
**在这一步完成之前，不做任何前段调参。**

**第二项：对 `vwap_hard_block long` 做定向后验，而不是直接调门槛**

已有数据（`vwap_hard_block long 2h avg +0.1254%`）有信号，但样本不足。  
目标：扩大后验样本，统计在 `vwap_score ∈ [0.08, 0.12)` 的 long 侧信号里，2h / 4h forward return 的均值、中位数、胜率，以及与 `vwap_score >= 0.12` 信号的对比。  
这一步的目标是确认"long 侧偏紧"是否是真实的、稳定的偏差，而不是单个窗口的噪声。  
**只有这一步的后验支撑足够，才考虑 long 侧定向放宽实验。**

**第三项：把 `volume_vwap_both_low` 和 `4H preflip` 的后验分别独立拆出来，不合并处理**

这两个条件的性质不同。`volume_vwap_both_low` 是保护型过滤，`4H preflip shrink` 是方向确认型过滤。它们应该被单独审，不能用同一个"前段偏紧"的结论一起处理。  
目标：对这两个条件下的 entry 候选，分别统计假阴性率（即条件触发但后续价格实际上走出了有利方向的比例）。  
**这一步的产出是：哪个条件更像是在正确执行任务，哪个条件更像是在多拦机会。**
