## 📝 修改内容

### 1. 恢复的三个核心风控

#### 风控 1: ATR 极端值阻断
```python
# 目的：防止在波动率异常高时开仓，避免被剧烈波动止损
# 阈值：ATR > 3.5 (相对于正常波动率的倍数)
# 动作：阻止开仓，返回 HOLD
```

**触发条件**:
- 仅在开仓时检查 (BUY/SELL)
- ATR 百分比 >= 3.5%

**设计理由**:
- ATR > 3.5% 表示市场处于极端波动状态
- 此时开仓极易被大幅波动触发止损
- 这是最重要的风控，必须保留

**预期影响**:
- 过滤掉极端行情下的危险开仓
- 对正常行情几乎无影响 (ATR 通常在 0.5%-2%)

---

#### 风控 2: 资金占用检查
```python
# 目的：防止资金占用过高时继续开仓，避免爆仓风险
# 阈值：预计资金占用 > 85%
# 动作：阻止开仓，返回 HOLD
```

**触发条件**:
- 仅在开仓时检查 (BUY/SELL)
- 预计资金占用 >= 85%

**计算方法**:
```python
projected_equity_usage = _estimate_equity_usage_ratio(
    account_summary,
    decision.target_portion_of_balance
)
```

**设计理由**:
- 资金占用 > 85% 时，账户几乎没有缓冲空间
- 一旦市场反向波动，容易触发强平
- 保留 15% 的缓冲资金应对突发情况

**预期影响**:
- 防止过度杠杆导致的爆仓风险
- 在正常仓位管理下很少触发 (当前单笔 25%，最多 3 个币种 = 75%)

---

#### 风控 3: 持仓浮亏强制退出
```python
# 目的：在持仓浮亏过大时强制平仓，防止亏损进一步扩大
# 阈值：浮亏 > 10%
# 动作：强制全平，返回 CLOSE
```

**触发条件**:
- 仅在持有仓位时检查
- 当前浮亏 >= 10%

**计算方法**:
```python
drawdown = _position_drawdown_ratio(position, current_price)
```

**设计理由**:
- 浮亏 > 10% 表示交易严重失误或市场发生结构性变化
- 及时止损比等待反弹更可靠
- 避免单笔亏损失控导致账户崩溃

**预期影响**:
- 作为最后的安全网，防止灾难性亏损
- 正常情况下应由止损机制 (2%) 先触发，此风控是兜底

## 🔍 实现细节

### 代码结构

```python
def _apply_pretrade_risk_gate(...):
    """Pretrade Risk Gate - 轻量级核心风控
    
    仅保留三个最关键的风控检查：
    1. ATR 极端值阻断 (ATR > 3.5 时阻止开仓)
    2. 资金占用检查 (占用 > 85% 时阻止开仓)
    3. 持仓浮亏强制退出 (浮亏 > 10% 时平仓)
    """
    
    # 初始化 gate_meta
    gate_meta = {"enabled": True, "action": "PASS", ...}
    
    # 风控 1: ATR 极端值阻断
    if operation in (BUY, SELL) and atr_pct >= 3.5:
        return HOLD decision with BLOCK reason
    
    # 风控 2: 资金占用检查
    if operation in (BUY, SELL) and equity_usage >= 0.85:
        return HOLD decision with BLOCK reason
    
    # 风控 3: 持仓浮亏强制退出
    if position exists and drawdown >= 0.10:
        return CLOSE decision with EXIT reason
    
    # 所有检查通过
    return original decision with PASS action
```

### 关键特点

✅ **轻量级**: 仅 120 行代码，相比之前的 672 行减少 82%

✅ **透明**: 每个风控都有清晰的注释和日志输出

✅ **易维护**: 逻辑简单，参数集中，易于调试

✅ **优先级明确**: 
- ATR 和资金占用 → 阻止开仓 (BLOCK)
- 浮亏退出 → 强制平仓 (EXIT)

## 📋 参数调优建议

### ATR 极端值阈值

| 阈值 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 3.0% | 保守策略 | 更安全 | 可能错过部分机会 |
| **3.5%** | **平衡策略 (当前)** | **安全与机会平衡** | **-** |
| 4.0% | 激进策略 | 更多交易机会 | 风险略高 |
| 5.0% | 高风险偏好 | 最大化交易频率 | 可能在大波动中亏损 |

**建议**: 先使用 3.5%，观察 1-2 周后根据实际触发频率调整。

### 资金占用阈值

| 阈值 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 80% | 保守策略 | 更多缓冲 | 可能限制交易 |
| **85%** | **平衡策略 (当前)** | **合理缓冲** | **-** |
| 90% | 激进策略 | 最大化资金使用 | 缓冲较少 |

**建议**: 保持 85%，当前配置 (75% 满仓) 有 10% 余量，足够安全。

### 浮亏退出阈值

| 阈值 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 8% | 保守策略 | 更快止损 | 可能过早退出 |
| **10%** | **平衡策略 (当前)** | **合理容忍度** | **-** |
| 12% | 激进策略 | 给交易更多空间 | 亏损可能扩大 |
| 15% | 高风险偏好 | 最大化持仓耐心 | 单笔亏损较大 |

**建议**: 保持 10%，这是最后一道防线，正常情况下应由 2% 止损先触发。

## 📈 监控指标

在启用这三个风控后，建议密切监控：

1. **ATR 阻断频率**: 
   - 目标：< 5% 的开仓尝试被阻断
   - 如果 > 10%，考虑提高阈值至 4.0%

2. **资金占用触发频率**: 
   - 目标：极少触发 (< 1%)
   - 如果频繁触发，说明仓位过重

3. **浮亏退出触发频率**: 
   - 目标：几乎不触发 (< 0.1%)
   - 如果频繁触发，说明止损机制有问题

4. **整体开仓频率**: 
   - 目标：3-5 笔/天
   - 如果 < 2 笔/天，说明风控过严

5. **胜率变化**: 
   - 目标：保持 45-50%
   - 如果显著下降，需要重新评估风控参数
