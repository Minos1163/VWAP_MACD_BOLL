## 二、为什么 77.27% 胜率只换来 +22.19%

### 2.1 资金使用本身偏保守

本次运行参数决定了收益弹性不会特别大:

- `default_target_portion = 0.18`
- `max_symbol_position_portion = 0.25`
- `max_positions = 2`
- `default_leverage = 2`
- `max_leverage = 2`

这意味着它更像是“高命中、中低风险”的放大器，而不是“高权益利用率”的冲收益配置。

### 2.2 胜率高，主要来自大量小胜，不是大量厚利润

全体交易统计:

- 平均单笔盈利: `+22.35`
- 平均单笔亏损: `-33.90`
- 平均盈利 / 平均亏损比: `0.66`
- 中位数盈利: `+5.75`
- 中位数亏损: `-21.26`

这说明:

- 这套系统不是“赢少亏大”的失败结构，因为它靠高胜率维持了正期望。
- 但它也不是“让盈利奔跑”的结构，因为绝大多数盈利单都很薄。

盈利单分布更能说明问题:

- `0~5 USDT`: `76` 笔
- `5~10 USDT`: `89` 笔
- `10~20 USDT`: `5` 笔
- `20~50 USDT`: `3` 笔
- `50~100 USDT`: `14` 笔
- `100+ USDT`: `17` 笔

也就是说:

- `204` 笔盈利单中，有 `165` 笔盈利小于 `10 USDT`
- 真正贡献利润的，是少数打到 `4% TP` 的趋势单

### 2.3 “stop_loss_intrabar” 名义上是止损，实际承载了大量小盈利出场

按出场原因拆分:

- `take_profit_intrabar`: `25` 笔，`25` 胜，PnL `+3135.35`
- `stop_loss_intrabar`: `218` 笔，`169` 胜，PnL `-653.53`
- `4h_shrink_exit`: `16` 笔，`8` 胜，PnL `+21.91`
- `signal_reverse`: `2` 笔，`0` 胜，PnL `-51.60`

进一步看 `stop_loss_intrabar`:

- 共有 `218` 笔
- 其中盈利单 `169` 笔
- 这些盈利止损单的平均盈利只有 `+5.34`
- 同类亏损止损单的平均亏损是 `-31.74`

结论:

- 高胜率很大一部分，是靠保本/跟踪/保护止损把单子小赚带走
- 但这些单子没有贡献多少权益曲线斜率
- 真正把收益拉上去的，是少量完整打到 `4%` 的趋势单

## 五、对“提高止损、活动止盈”的判断

这里将“提高止损”解释为:  
把止损位抬高，也就是**收紧初始风险和更快锁盈**。

### 5.1 为什么应该收紧止损，而不是放宽止损

从本次成交看，真正拖累收益的不是“止损太紧导致错失大趋势”，而是:

- 某些通道的亏损仍然偏深
- 很多盈利单在止损逻辑下只留下很薄的利润

特别是 `red_bar_growing + long_dual_support`:

- 很多胜利单只赚 `0~5` 或 `5~10 USDT`
- 但亏损单却经常达到 `-50~-90 USDT`

因此更合理的方向不是“放宽止损”，而是:

- 更早保本
- 更早抬高止损
- 对弱趋势多头更早退出

### 5.2 为什么应该做更主动的止盈

当前只有 `25` 笔真正命中 `4% TP`，却贡献了 `+3135.35` 的利润。  
这说明 `4% TP` 本身没有问题，问题在于:

- 太多单子走不到 `4%`
- 这些单子先给出小浮盈，然后又被保护性止损带走

因此更合理的思路是:

- 保留远端 `4% TP` 作为趋势奖金
- 同时增加更主动的分级止盈，让“只走一半路”的单也能留下更多利润

- 减少 `-50~-90 USDT` 这类深亏单
- 胜率可能继续抬高
- 单笔盈利上限不会提升，但净收益曲线会更干净

### 6.2 方向 B: 保留 `4%` 远端 TP，但增加主动分级止盈

建议:

- 不要把总 TP 直接从 `4%` 下砍到 `2%`
- 而是增加更早的主动落袋

建议结构:

- `25%~35%` 仓位在 `+0.8% ~ +1.2%` 先落袋
- 再在 `+2.0%` 左右减第二段
- 剩余仓位继续保留 `4%` 远端 TP 或 trailing

理由:

- 当前很多单子只走到小盈利区间后回落
- 如果不先落一部分利润，高胜率最后只会体现在“小赚次数多”

这套策略当前已经达成“频率和胜率”，但还没有达成“单位胜利的盈利厚度”。  
下一步的核心不是再追求更高胜率，而是把大量小胜转化成更高的单笔留存利润。
